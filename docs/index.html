02 / Comparison

Same model size. Different economics.

Breakthrough path

The verifier became cheap enough to convert already-good draft acceptance into wall-clock speed. Row4 storage and TG-LUT M=5 kernels made the target verification shape the lever.

03 / Work

The grind, reduced to what mattered

Q1

Verifier reads became reusable.

Row4 turned the verifier into the right shape: one packed target read feeding five FP32 accumulators. Acceptance did not need to improve; verification cost needed to fall.

Q2

Ternary math was real.

The checkpoint was strict ternary affine: `q in {0,1,2}`, code 3 unused, `bias=-scale`, `weight=scale*(q-1)`. That justified custom row2 and head kernels.

Q2

Head materialization was killed.

The verifier-only `lm_head -> argmax` path avoided full `[5, vocab]` logits and moved end-to-end from `17.49` to `18.55`, then to `19.68 tok/s` with strict ternary head and split-K down.

Q2

Top-K was scientifically useful, not victorious.

Base top-16 containment was perfect on Fibonacci, but the fastest fused top-K Markov scorer reached `19.61 tok/s`, below the exact `19.68 tok/s` path. It stays opt-in.
